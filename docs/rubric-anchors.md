# Phase 4 멤버 루브릭 10항목 채점 앵커 가이드

- **목적**: `lib/derive.mjs` `RUBRIC_ITEMS`(물리 55 / 해석 45, 10항목)의 현행 구조·배점·기존 15인 분포(`79.0~95.8`)를 유지한 채, 큐레이터가 일관된 청취 기준으로 채점할 수 있는 **관찰 가능 앵커(Observable Anchors)** 정의.
- **전제**: `breath`는 `interpretive`(10점), `live`는 `interpretive`(5점)로 유지하며, 기존 점수 재채점은 전제하지 않는다. 기술 용어는 `(English)`를 병기한다.

---

### 1. 발성 (`vocalization`, 만점 15, `physical`)
- **정의**: 성대 접촉(cord closure), 공명 배치(resonance placement), 성구 연결(register connection) 등 소리 생성의 기본 메커니즘 완성도를 평가한다.
- **포함 / 제외**: **포함** — 성대 내전 효율, 흉성·믹스·두성 전환의 매끄러움, 목 조임 없는 공명 균형 / **제외** — 장식 기교(→`technique`), 호흡 길이·숨소리 관리(→`breath`), 최고/최저 한계 음역(→`range`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `14.3–15.0` | 전 음역에서 성대 접촉과 공명 밸런스가 균일하며, 성구 전환(passaggio) 이음새가 거의 들리지 않음 |
| `13.5–14.2` | 주 음역·믹스 보이스가 안정적이고 공명감이 뚜렷하나, 극고음·급전환에서만 미세한 힘 들어감이 감지됨 |
| `12.8–13.4` | 중저음~중고음 발성은 탄탄하고 선명하나, 고음역 진입 시 진성 밀착 유지나 공명 집중력이 다소 옅어짐 |
| `12.0–12.7` | 기본 발성 밸런스는 준수하나, 성구 전환부에서 음색 이질감이나 목 긴장이 간헐적으로 들림 |
| `11.3–11.9` | 가성/진성 분리 또는 비강·인후 긴장이 잦고, 고에너지 구간에서 발성 지지력이 약해짐 |
| `<11.3` | 성대 접촉이 불안정하거나 바람 새는 소리·목 조임이 곡 전반에 두드러짐 |

- **관찰 포인트**: ① 흉성→믹스→두성 전환 구간에서 음질이 갑자기 얇아지거나 끊기지 않는가 ② 고음 클라이맥스 후 다음 소절 발성이 거칠어지지 않는가 ③ 저음에서 성대가 풀리지 않고 울림을 유지하는가
- **흔한 오판**: 화려한 비브라토·꺾기 기교(`technique`)나 예쁜 음색(`tone`)을 발성 완성도로 혼동해 중복 가산하는 오류.

---

### 2. 음정 (`pitch`, 만점 10, `physical`)
- **정의**: 멜로디 음고(pitch accuracy), 도약(interval leap), 전조 및 화음 구간에서의 음정 정확도를 평가한다.
- **포함 / 제외**: **포함** — 반음 이하 미세 플랫/샤프(intonation), 도약 후 착지 정확도, 비브라토 중심 음고 유지 / **제외** — 무보정 라이브 환경만의 흔들림(→`live`), 피치 안정성 외 음색 매력(→`tone`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 큰 도약·전조·빠른 패시지에서도 중심 음고가 흔들림 없이 정중앙에 꽂힘 |
| `9.0–9.4` | 전반적인 인토네이션이 매우 정확하며, 감정적 끝음 처리에서만 미세한 흔들림이 극히 드물게 나타남 |
| `8.5–8.9` | 멜로디 라인은 안정적이나, 연속 고음 도약이나 비브라토 말미에서 간헐적 미세 플랫/샤프가 들림 |
| `8.0–8.4` | 주요 프레이즈 음정은 맞으나, 체력 소모가 큰 후반부·저음 착지에서 음정 이탈이 가끔 감지됨 |
| `7.5–7.9` | 난이도 높은 도약·전조나 불안정한 호흡 뒤에서 반음 안팎의 흔들림이 반복적으로 들림 |
| `<7.5` | 곡 전반에 걸쳐 음고 이탈이 잦아 멜로디 안정감이 눈에 띄게 저하됨 |

- **관찰 포인트**: ① 옥타브·6도 이상 큰 도약 후 첫 음이 미끄러지지 않고 바로 맞는지 ② 롱톤 끝음에서 피치가 아래로 처지지 않는지 ③ 코러스 화음/전조 직후 기준음을 정확히 잡는지
- **흔한 오판**: 스튜디오 커버의 피치 보정(Melodyne 등) 결과를 멤버의 생음정 실력으로 과대평가하는 스튜디오 보정 편향(studio correction bias).

### 3. 리듬 (`rhythm`, 만점 10, `physical`)
- **정의**: 박자 정확도(timing accuracy), 그루브(groove), 프레이즈 진입·이탈 타이밍의 일관성을 평가한다.
- **포함 / 제외**: **포함** — 템포 유지, 싱코페이션(syncopation)·빠른 가사 딕션 리듬, 반주와의 밀당(pocket) / **제외** — 의도적 루바토(rubato)로 감정을 실는 해석(→`expression`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 빠른 템포·변박·싱코페이션에서도 반주와 완벽히 맞물리며, 탄력 있는 그루브를 주도함 |
| `9.0–9.4` | 업템포·발라드 모두 박자 안착이 정확하고, 프레이즈 끝맺음 길이가 깔끔함 |
| `8.5–8.9` | 전반적 박자감은 안정적이나, 가사가 밀집된 구간이나 엇박 진입에서 미세하게 앞/뒤로 쏠림 |
| `8.0–8.4` | 정박 위주 곡은 무난하나, 빠른 리듬 전환·스윙·래핑 성향 구간에서 타이트함이 다소 떨어짐 |
| `7.5–7.9` | 호흡 부족이나 고음 준비 직전 프레이즈 진입이 늦어지거나 박자가 들쭉날쭉해짐 |
| `<7.5` | 반주(MR)와 박자가 자주 어긋나 리듬 일관성이 전반적으로 흔들림 |

- **관찰 포인트**: ① 16분음표 밀집 구간(J-POP 특유 빠른 소절)에서 자음이 박자 밖으로 밀리지 않는가 ② 쉼표 뒤 재진입(pick-up)이 정확한가 ③ 느린 발라드에서 박자가 늘어지지 않고 추진력을 유지하는가
- **흔한 오판**: 리듬이 살짝 느슨한 것을 '감성적 표현(`expression`)'으로 오해하거나, 반대로 발라드만의 루바토를 박자 실수로 감점하는 오류.

### 4. 음역 (`range`, 만점 10, `physical`)
- **정의**: 실전 곡에서 음악적으로 활용 가능한 가용 음역폭(usable range)과 높은·낮은 테시투라(tessitura) 소화력을 평가한다.
- **포함 / 제외**: **포함** — 저음~초고음 가용 폭, 고음 테시투라 체류 지속력, 가성/진성 양방향 음역 확장 / **제외** — 음역 내부 발성 자체의 퀄리티(→`vocalization`), 고음 기교 장식(→`technique`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 저음부터 초고음까지 가용 폭이 매우 넓고, 높은 테시투라 곡도 여유롭게 전곡 완주함 |
| `9.0–9.4` | 고음역과 중저음역 모두 실전 배치 가능한 음역이 넓으며, 클라이맥스 최고음 도달이 안정적임 |
| `8.5–8.9` | 평균 이상의 넓은 음역을 보유하나, 극고음 지속 구간이나 극저음 착지에서는 다소 한계가 보임 |
| `8.0–8.4` | 주력 중·고음역대는 안정적이나, 높은 원키 곡에서 키 조절이나 가성 회피가 간헐적으로 필요함 |
| `7.5–7.9` | 편안히 쓰는 음역대(comfort zone)가 비교적 좁고, 일정 음고 이상에서 급격히 힘이 부침 |
| `<7.5` | 원곡 음역 소화가 제한적이어서 잦은 키 하향 또는 멜로디 우회가 관찰됨 |

- **관찰 포인트**: ① 단발성 최고음 1음 찍기가 아니라 후렴 고음 테시투라를 몇 소절 이상 버티는가 ② 저음 도입부에서 소리가 묻히지 않고 음정이 잡히는가 ③ 다양한 키·성별 원곡을 원키로 소화하는 폭이 넓은가
- **흔한 오판**: 고음 한 번의 임팩트만으로 음역을 과대평가하고, 저음역 부족이나 고음 지속력 한계를 간과하는 오류.

### 5. 성량 (`volume`, 만점 10, `physical`)
- **정의**: 믹싱 음량이 아닌 **발성 자체의 음향 투사력(acoustic projection)**, 공명 밀도, 그리고 여린 소리~강한 소리의 출력 폭(dynamic power)을 평가한다.
- **포함 / 제외**: **포함** — 악기 편성이 두꺼운 후렴을 뚫고 나오는 성대 파워, 크레센도 출력 여유 / **제외** — 단순 음원 마스터링 볼륨(LUFS)·마이크 게인, 감정적 강약 선택 의도(→`expression`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 두꺼운 록/오케스트라 반주 위에서도 소리가 얇아지지 않고, 압도적 투사력과 출력 폭을 보여줌 |
| `9.0–9.4` | 후렴 파워와 공명 밀도가 뚜렷하며, 여리게 부를 때도 힘이 빠지지 않는 출력 여유가 있음 |
| `8.5–8.9` | 반주와 균형을 잘 이루는 탄탄한 성량이나, 극대 음량 클라이맥스에서 폭발력 한계가 살짝 보임 |
| `8.0–8.4` | 잔잔한 편성에서는 충분하나, 강렬한 밴드 사운드 구간에서는 반주에 다소 묻히는 경향이 있음 |
| `7.5–7.9` | 전반적으로 출력이 가볍거나 얇아 강한 에너지가 필요한 곡에서 존재감이 약해짐 |
| `<7.5` | 발성 투사력이 부족해 컴프레서·볼륨 보정 없이는 보컬이 반주 뒤로 밀림 |

- **관찰 포인트**: ① 드럼·일렉기타가 터지는 후렴에서 보컬이 컴프레션에 눌리지 않고 앞으로 뻗는가 ② 마이크를 떼거나 노래방송 무반주 구간에서도 울림 밀도가 유지되는가 ③ 큰 소리를 낼 때 찢어지지 않고 배음(overtone)이 함께 커지는가
- **흔한 오판**: 유튜브 음원 믹싱 게인/컴프레서가 크게 걸린 트랙을 성량이 큰 것으로 오인하는 **믹싱 게인 편향(mixing gain bias)**.

### 6. 음색 (`tone`, 만점 10, `interpretive`)
- **정의**: 보컬 고유의 팀브르(timbre) 매력도·식별성(recognizability)과 곡 분위기·장르에 맞는 음색 질감 운용(tone color control)을 평가한다.
- **포함 / 제외**: **포함** — 개성적 톤 식별력, 맑기/허스키/따뜻함 등 질감의 매력, 곡 분위기에 맞춘 톤 변주 / **제외** — 성구 결함으로 생기는 거친 잡음(→`vocalization`), 강약·감정 서사 설계(→`expression`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 첫 소절만 들어도 각인되는 독보적 음색 매력과, 곡·음역에 따라 질감을 유연하게 바꾸는 통제력을 겸비 |
| `9.0–9.4` | 고유 팀브르의 개성과 선명도가 뛰어나며(캐릭터 톤 포함), 듣기 좋은 질감이 전곡에서 유지됨 |
| `8.5–8.9` | 매력적이고 호감 가는 음색을 지녔으나, 특정 음역이나 낯선 장르에서 음색 특색이 다소 평범해짐 |
| `8.0–8.4` | 깔끔하고 거슬림 없는 음색이나, 타 멤버 대비 뚜렷한 음색 각인력이나 질감 변주가 제한적임 |
| `7.5–7.9` | 음색은 무난하나 고음·강성 구간에서 톤이 거칠거나 단조롭게 들리는 편임 |
| `<7.5` | 음색 질감이 고르지 못하거나 곡의 전반적 사운드와 겉도는 인상을 줌 |

- **관찰 포인트**: ① 1절 A파트 첫 두 소절의 무반주/약반주 구간에서 보컬 톤 자체가 주는 흡입력이 있는가 ② 고음과 저음의 음색 캐릭터가 완전히 다른 사람처럼 쪼개지지 않고 개성을 잇는가 ③ 발라드와 업템포에서 톤 질감(공기감/단단함)을 다르게 쓰는가
- **흔한 오판**: 개인 취향에 맞는 특정 목소리 타입(예: 저음 허스키 vs 미성)만 높게 주고, 고유 캐릭터 톤의 개성 가치를 간과하는 편향.

---

### 7. 테크닉 (`technique`, 만점 10, `interpretive`)
- **정의**: 비브라토(vibrato), 꺾기·벤딩(scoop/bend), 런/애드리브(runs/riffs) 등 의도적 가창 장식 기교의 정교함을 평가한다.
- **포함 / 제외**: **포함** — 기교 구사의 정확성·자연스러움, 장르 어법 기교(예: 보컬로이드/J-POP 샤우팅·코부시·위스퍼 릴리스) / **제외** — 기본 성대 접촉·공명 메커니즘(→`vocalization`), 순수 감정 완급(→`expression`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 비브라토·꺾기·벤딩·애드리브 등 다채로운 기교가 과잉 없이 정교하게 곡에 녹아듦 |
| `9.0–9.4` | 비브라토 주기와 꺾기·벤딩 기교가 세련되며, 장르별 요구 테크닉을 능숙히 구사함 |
| `8.5–8.9` | 기본 비브라토와 끝음 처리 기교는 안정적이나, 고난도 런/빠른 꺾기 구사는 제한적임 |
| `8.0–8.4` | 무난한 끝음·장식 처리는 가능하나, 기교 레퍼토리가 단순하고 패턴이 반복되는 편임 |
| `7.5–7.9` | 기교 구사 빈도가 적거나, 비브라토·꺾기 시도 시 음정/박자가 간헐적으로 흔들림 |
| `<7.5` | 기본 장식 기교가 거의 없거나, 기교가 부자연스럽게 끊겨 곡 흐름을 방해함 |

- **관찰 포인트**: ① 끝음 비브라토의 진폭과 속도가 일정하고 자연스럽게 감쇠하는가 ② 꺾기·벤딩·애드리브 구사 시 음정과 박자가 흔들리지 않는가 ③ 기교가 곡의 맥락에 어울리게 절제되어 쓰이는가
- **흔한 오판**: 기본 발성(`vocalization`)의 안정감을 테크닉 점수로 중복 계산하거나, 기교가 적은 담백한 곡을 테크닉 부족으로 깎는 오류.

### 8. 표현력 (`expression`, 만점 10, `interpretive`)
- **정의**: 가사 전달, 감정선 구축, 다이나믹(강약) 대비와 프레이징 설계를 통해 곡의 서사와 몰입감을 완성하는 능력을 평가한다.
- **포함 / 제외**: **포함** — 벌스→코러스 기승전결, 다이나믹·음색 대비 설계, 숨결·속삭임·호소력 등 감정 뉘앙스 / **제외** — 순수 음향 출력 크기 자체(→`volume`), 장식 기교의 기계적 정확도(→`technique`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 벌스-프리코러스-코러스의 감정 아크가 입체적이며, 단어 하나·쉼표 하나까지 서사 몰입감이 극대화됨 |
| `9.0–9.4` | 곡 분위기 전환과 강약 대비가 선명하고, 감정 전달과 가사 뉘앙스 살리기가 매우 설득력 있음 |
| `8.5–8.9` | 곡의 전반적 정서와 캐릭터 색깔은 잘 살리나, 절정과 여백의 미세한 대비 폭은 다소 일정함 |
| `8.0–8.4` | 멜로디 전달은 충실하나, 1절·2절·후렴 간 감정 고조나 다이나믹 변화가 비교적 평면적임 |
| `7.5–7.9` | 가사·음정 수행에 집중되어 감정 뉘앙스 변주나 극적 몰입 유도가 약하게 느껴짐 |
| `<7.5` | 곡의 정서와 무관하게 단조롭고 기계적인 가창으로 들림 |

- **관찰 포인트**: ① 1절과 마지막 후렴의 같은 멜로디를 다르게 해석해 빌드업하는가 ② 속삭이듯 작게 시작해 클라이맥스로 밀어 올리는 다이나믹 대비가 있는가 ③ 가사의 감정(슬픔, 장난기, 결의 등)이 발음·어조에 실리는가
- **흔한 오판**: 단순히 고음을 크게 지르는 것(`volume`)을 표현력이 좋다고 보거나, 반대로 과장된 감정 처리를 무조건 고평가하는 오류.

---

### 9. 호흡 (`breath`, 만점 10, `interpretive` 유지)
- **정의**: `interpretive` 그룹 배치를 유지하되, 프레이징 내 **호흡 배분·숨 고르기 위치의 음악적 자연스러움(breath phrasing)**과 긴 소절을 지탱하는 **호흡 지지력(breath support)**을 함께 평가한다.
- **포함 / 제외**: **포함** — 롱 프레이즈 유지력, 흡기 타이밍·들숨 소음 절제, 프레이즈 끝의 호흡 고갈 방지 / **제외** — 성대 접촉 자체의 효율(→`vocalization`), 생라이브 환경 특유의 떨림(→`live`).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `9.5–10.0` | 호흡이 긴 곡에서도 숨이 차는 기색이 전혀 없으며, 숨 들이쉬는 타이밍조차 프레이징의 일부처럼 자연스러움 |
| `9.0–9.4` | 호흡 배분이 계획적이어서 프레이즈 끝까지 지지력이 유지되고, 불필요한 들숨 소음이 거의 없음 |
| `8.5–8.9` | 일반 곡에서는 호흡이 안정적이나, 쉼표가 짧은 연속 소절에서 급한 들숨이 간헐적으로 들림 |
| `8.0–8.4` | 중반까지는 무난하나, 고에너지 후반부에서 프레이즈 끝음이 호흡 부족으로 짧아지거나 힘이 빠짐 |
| `7.5–7.9` | 빠른 곡·고음 연속 구간에서 잦은 숨 고르기 끊김이나 들숨 잡음이 비교적 자주 감지됨 |
| `<7.5` | 호흡 지지가 전반적으로 짧아 가사 소절이 중간에 부자연스럽게 잘림 |

- **관찰 포인트**: ① 숨 쉴 틈이 적은 J-POP 후렴 끝음까지 소리가 죽지 않고 지지되는가 ② 마이크 앞 급한 들숨(gasp)이 리듬이나 정서를 깨지 않는가 ③ 약하게 부르는 구간에서 호흡이 새어 피치가 떨어지지 않는가
- **흔한 오판**: 스튜디오 편집에서 들숨(breath) 트랙을 컷·디브레스(de-breath) 처리한 음원만 듣고 실제 호흡 배분 능력을 과대평가하는 오류.

### 10. 라이브 (`live`, 만점 5, `interpretive` 유지)
- **정의**: 스튜디오 후반 보정이 없는 **무보정 라이브·3D 콘서트·노래방송 환경에서의 가창 일관성(live consistency)**을 평가한다. (보컬 차원이 아닌 검증 맥락 지표)
- **포함 / 제외**: **포함** — 생라이브에서의 음정·호흡·발성 재현율(스튜디오 음원 대비 낙차 폭), 3D 움직임/장시간 방송 중 유지력 / **제외** — 스튜디오 녹음 커버만의 완성도(→각 개별 항목).

| 점수 구간 | 관찰 가능한 청취 기준 (Observable Descriptor) |
|---|---|
| `4.8–5.0` | 무보정 라이브·3D 무대에서도 음원 수준에 육박하는 음정·성량·호흡 일관성을 유지함 |
| `4.5–4.7` | 라이브 현장감 속에서도 핵심 음정과 발성 안정감이 탄탄하며, 원곡 대비 기복이 매우 적음 |
| `4.3–4.4` | 전반적 라이브 소화력이 안정적이나, 3D 안무나 고음 연속 구간에서 가벼운 흔들림이 보임 |
| `4.0–4.2` | 노래방송·라이브 가창은 준수하나, 스튜디오 커버 대비 음정·호흡 기복이 눈에 띄게 커짐 |
| `3.8–3.9` | 라이브 편차가 존재해 컨디션·곡 난이도에 따라 피치 이탈이나 체력 저하가 종종 드러남 |
| `<3.8` | 무보정 환경에서 음정·호흡 유지 편차가 커서 음원 대비 일관성 낙차가 뚜렷함 |

- **관찰 포인트**: ① 스튜디오 커버(`solo_cover`)와 노래방송/라이브 클립(`live_special`) 사이의 음정·성량 낙차가 얼마나 작은가 ② 한 곡 안에서 2~3절로 갈수록 피로도가 급격히 누적되지 않는가 ③ 아카펠라/무반주 순간에도 음정 기준을 잃지 않는가
- **흔한 오판**: 라이브 클립 자체가 적은 멤버에게 음원 인상만으로 높은 점수를 추정 부여하거나, 방송 마이크 음질 열화를 실력 저하로 착각하는 오류.
